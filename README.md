# Casapiccola Imóveis

Banco de dados de imóveis da Casapiccola: casas, condomínios e loteamentos.

Site: https://luizbpejnovic.github.io/Banco-de-Dados-da-Casapiccola-Im-veis/

- `index.html` é a página, com os dados dos imóveis dentro dela.
- Os arquivos `.jpg` e `.mp4` são as fotos e os vídeos.

Os imóveis são editados no banco de dados da Casapiccola no Claude. Para atualizar o site, gere um novo `index.html` e substitua o antigo.
